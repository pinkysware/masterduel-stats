Master Duel Stats 使用指南

随软件附带的使用说明（中文）。界面里：看板 → 设置 → 使用指南 → 打开。

1. 快速上手

1.1 四个包怎么选

四个包功能完全一样，选一个安装方式即可：

包适合谁
masterduel-stats-Setup-x.y.z.exe想要一键安装、开始菜单快捷方式的用户
masterduel-stats-vx.y.z-win64-full.zip解压即用，不写注册表；换电脑直接拷文件夹
masterduel-stats-vx.y.z-win64-lite.zip精简便携包（不含卡图与离线卡组清单，首次联网会自动补）
masterduel-stats-vx.y.z-patch-win64.zip已经装过旧版本的用户升级用（直接解压覆盖）

1.2 安装位置：为什么建议装到普通文件夹

安装时如果一路「下一步」，默认会装到 C:\Program Files。建议改成普通文件夹
（例如 C:\MasterDuelStats），原因有两个：

  • Program Files 对普通用户是只读目录：以后用补丁包升级时覆盖不了里面的 程序代码（要管理员权限），升级会失败或要额外操作；
  • 装在那里的话，你的对局数据会被改存到 C:\Users\<你>\AppData\Local\MasterDuelStats， 不再跟程序放在一起，换电脑时容易漏拷。

装在普通文件夹时，数据就在 <安装目录>\data，整个文件夹拷走就等于备份了全部。

提示：安装器里把路径改掉即可；已经装在 Program Files 的也能用，只是升级
和迁移数据时麻烦一点。

1.3 第一次打开

  1. 双击桌面/开始菜单的 Master Duel Stats（便携版双击 start.bat）；
  2. 首次启动会弹环境自检窗口：确认「数据目录 / 游戏 / 采集器 / 卡组清单」 四行都是正常状态（游戏目录会自动探测，探测不到时手动选一次你的 Master Duel 安装目录）；
  3. 保持看板开着，启动游戏打一局；
  4. 打完回到看板：战绩页应该出现这一局——出现即说明整条链路在工作。

1.4 数据怎么存

  • 便携版 / 普通文件夹安装：数据在 <程序目录>\data（数据库、对局记录、 卡图缓存都在里面）；
  • 「游戏对局数据」的存放位置可以在 看板 → 设置 → 游戏对局数据 里改到 其它磁盘；
  • 换机 / 重装前：看板 → 导出 → 备份全部数据…，一个 zip 带走全部； 恢复用同一个页面的「从备份恢复…」。

2. 悬浮窗

游戏运行时屏幕上会有一个小窗（悬浮窗），实时显示统计。看板 → 设置里可以
控制「游戏启动时弹悬浮窗」和「当窗口关闭时」（隐藏到托盘还是退出）。

2.1 上下两块

  • 上块（总览 / 先后攻统计）：只统计本轮——上一局结束到现在这段 时间里打的天梯 + 巅峰局；超过一小时没打就清零重来。活动、杯赛的局 不进这两块。
  • 下块（最近对局）：最近几局，一行一局；可以用鼠标拖拽窗口大小， 显示的行数跟着变。

2.2 对手卡组那一格（重要）

最近对局每行右边有对手卡组格，它的三种状态：

  1. 显示卡组名（正常底色）：已确认。可能是你手动标的，也可能是 自动识别的。
  2. 显示卡组名（黄色底、带 ! 角标）：软件的猜测建议—— 根据对手打出的卡反推。点一下这一格就确认入库，不用开任何面板。
  3. 写「未知卡组」：证据不够，点一下会打开选择面板手动挑 （面板里也能搜中文 / 别名 / 日文名 / 拼音首字母）。

自动入库：置信度高且至少 3 张卡对得上时，建议会直接确认、
不用你点（那一格会自动变成正常底色）；只有一两张卡对得上的局宁可让你
亲手确认，机器不替你猜。

我方卡组的识别顺序：自动识别优先（天梯 / 巅峰 / DC 杯各自读游戏里
对应的卡组位）；自动识别没出结果时，用你在悬浮窗手动指定的卡组兜底
（点卡图选择，会固定下来直到你再换）。识别条上的「刷新」按钮 = 真读一次
内存：会按当前游戏状态重读对应的卡组槽位（点下有 1~2 秒读取，读不到会
弹窗说明原因）。

标错了怎么办：点那一格重新选；撤销或换绑都可以，随时改。

2.3 顶部「卡组确认」提示条

悬浮窗顶部会有一条你自己的卡组确认条：

  • 没识别到时提示「点击卡组编辑获取」；
  • 识别到后显示卡图 + 名字，点「确认」后收起；
  • 换了卡组它会再次出现——看到它就顺手确认一下，我方卡组统计才准。

天梯和巅峰在游戏里是两套独立的卡组位，软件按你打的模式自动读对应那套
（1.1.6 起），互不干扰。DC 杯也是独立卡组位，但游戏的卡表数据只在
「编辑牌组」打开期间暴露（第三方工具都一样，untapped 也会显示「未知牌组」），
对局里通常读不到——以确认条手动指定为准；软件仍会尽力自动读，读到了
就不用手选。其它活动局同理。

2.4 窗口操作

  • 左缘两条标题条可折叠；右上角三个按钮：- 隐藏到托盘、□ 最大化、 × 按设置里的「当窗口关闭时」行事；
  • 窗口可拖拽、可缩放，尺寸会记住。

3. 看板逐页

看板左侧是导航：上面一排是战绩 / 对局分析 / 卡组 / 导出 / 悬浮窗，
中间「查询」分组是禁限表 / 查卡 / 礼盒，最下面是设置。

3.1 战绩

每一局一行：我方卡组（图+名）、胜负、先/后、局前/局后段位、对手卡组（图+名）。
页面顶部有月度热力图（每天一格，颜色深浅 = 当天局数），点某个月就切换到
那个月的对局。胜负修正：在那一行上点结果格可以改（标错了的胜负能修）。
「我方手坑 / 对方手坑」两列默认关着，在 设置 → 显示我方手坑列 / 显示对方
手坑列 打开。

3.2 对局分析

我方卡组 × 对手卡组 的胜率矩阵：行是我用过的卡组，列是遇到过的对手卡组，
每格是胜率。三个页签：综合 / 先攻 / 后攻（切页签只换格内数字，不重排）。
筛选器：按月份、按模式（天梯 / 巅峰 / DC 杯 / 活动四类）。页面下部有
手坑汇总（我方用过 / 对方用过 / 对方独有）。

3.3 卡组（三个页签）

页签 1「卡组名管理」——管理卡组名字与卡图的中央表：

  • 每行可改：中文名、别名（多个用 / 分隔）；改完点「保存」生效；
  • 点那一行的卡图可以换图：搜卡名 → 在候选列表里点一行（行右出现「确认」）→ 「获取卡图」→「保存」。自定义卡组同样操作；
  • 顶部「自定义卡组名」输入行：打名字 → 添加 → 保存后成为你自己的卡组条目；
  • 最右「删除」按钮：从表里拿掉一行（保存才真正落盘）；
  • 别名的作用：对手卡组的其它叫法（比如站内叫 X、贴吧叫 Y）落到同一条统计； 同一卡组的不同译名不要建两行，写进别名。

页签 2「Tier 表」——当前环境的卡组梯队（TIER 1 / 2 / 3 / TRENDING，
来源 masterduelmeta，月度更新）。点任意一个卡组芯片，直接跳进页签 3 看
那张卡组的构成。

页签 3「卡组构成」——一张卡组的逐卡清单：主卡组 / 额外卡组两栏卡图网格，
每张卡标「N 副里有 N 副带它，占 P%」。顶部可以换卡组（下拉可搜索：
中文 / 别名 / 日文都行）、按携带率过滤与排序；页头显示参照库快照日期
（数据 = 月度参照库，过期了在 设置 → 参照库刷新 更新）。

3.4 导出

  • 按月份 + 模式筛选对局，预览后导出 CSV / JSON（给表格软件用）；
  • 全量备份区（页面底部）：
  • 「备份全部数据…」：一个 zip 带走全部数据与可改配置 —— 换机、重装、 大版本更新前先备份；
  • 「从备份恢复…」：选 zip 恢复（同名覆盖，下次启动界面时生效）；
  • 「导出诊断包…」：报障必带 —— 软件环境 + 日志 + 最近对局概况打包， 发给开发者就能定位问题，不用截图猜。

3.5 悬浮窗（设置页）

目前是占位页：悬浮窗的功能开关之后会集中在这里。悬浮窗本身的列显隐、
行为设置先在「设置」页与悬浮窗右键菜单里。

3.6 禁限表（查询分组）

当前限制卡表三分组：禁止 / 限制 / 准限制（每张卡带整卡图），下面是
最近的禁限变更列表（哪些卡在哪个版本被禁/限/解禁）。数据月度更新。

3.7 查卡（查询分组）

输入卡名（三语都行）→ 本地卡名表即时给候选 → 点候选用默认浏览器打开
ygocdb 页面看效果文与卡图。离线可用（本地表 14610 张），不联网抓站。

3.8 礼盒（查询分组）

读游戏内存里的未领取礼盒条目，按领取期限日期分组，可展开逐条明细。
点「读取礼盒」才读一次（不影响游戏）。

5. 常见问题（FAQ）

Q：装完打了一局，怎么没有统计？
看板标题栏看采集器状态是否在跑（它与界面同开同关）；确认刚才那局是
天梯 / 巅峰 / DC 杯（部分活动模式不进统计）；首局前如果顶部弹出「卡组确认」
条，先点一下确认。

Q：对手卡组识别错了怎么改？
点悬浮窗那一格（或战绩页对手卡组格）重新选；选错随时能改，统计会跟着更新。

Q：我方卡组没识别（要我手选）？
天梯与巅峰是两套卡组位，1.1.6 起自动识别；旧版本先在游戏里打开一次
卡组编辑界面（天梯或巅峰的都行）。还没识别时，顶部确认条点「确认」也能指定。

Q：DC 杯 / 活动局的卡组认不出？
DC 杯是独立卡组位，且游戏的卡表数据只在「编辑牌组」打开期间暴露
（untapped 同样显示「未知牌组」），对局里通常读不到——确认条手动指定
为准；软件仍会尽力自动读，读到了就不用手选。其它活动局同理，都不是 bug。

「点开游戏『编辑牌组』再返回」这个动作对所有模式都有效：天梯 / 巅峰
本来就会自动识别（编辑是兜底），活动局靠它更新「当前卡组」兜底，DC 杯则是
唯一能读到卡表的时机。
Q：我的卡组怎么显示成英文站内名 / 为什么有两个名字？
覆盖表以「中文名」为准，站内英文名是原始键。你在「卡组名管理」里把中文名
补上/改掉即可；同一卡组的其它叫法写进「别名」列，不要建重复条目。

Q：数据存在哪？能不能搬走？
普通文件夹安装：<程序目录>\data，整个目录拷走就能用。装在 Program Files
的：数据在 C:\Users\<你>\AppData\Local\MasterDuelStats。想迁移用
导出页的「备份全部数据…」→ 新机器「从备份恢复…」。

Q：换电脑 / 重装系统，数据怎么办？
老机器：导出页「备份全部数据…」存好 zip；新机器装好软件后
「从备份恢复…」选那个 zip，重启界面即完成。

Q：出问题了怎么反馈？
导出页「导出诊断包…」，把生成的文件发给开发者（包含环境与日志，
不含任何账号凭据），比描述现象快得多。

Q：怎么升级？
补丁包是全量代码快照：1.1.2 起的任意旧版本都可以直接用最新补丁覆盖升级，
你的对局数据不会被动；也可以用 full 包 / Setup 重装（数据各自按 1.1 的
数据目录规则保留）。
