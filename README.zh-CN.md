# Master Duel Stats（Master Duel 战绩统计）

[English](README.md) | **简体中文** | [日本語](README.ja.md)

一个**纯本地**的《游戏王 Master Duel》桌面战绩统计工具：常驻采集器在你打完
每一局的瞬间自动归档进本地 SQLite 数据库；一个置顶悬浮窗加一块完整看板，
把胜负、对手卡组、段位起伏和环境的分析直观地摆在你面前。界面支持
**英文 / 中文 / 日文**（看板设置里实时切换）。

## 功能

- **悬浮窗**：置顶小窗实时显示本轮总览 / 先后攻统计 / 最近对局；点对手
  卡组格直接标注；三语界面在设置里原地切换。
- **看板**：月历热力图、战绩总览、逐局记录、我方 × 对手胜率矩阵、
  Tier 表、禁限表、卡组构成参照、礼盒查询、按月按模式导出 CSV / JSON。
- **自动采集**：常驻采集器在你打游戏的同时自动解码并归档每一局，零操作。
- **对手卡组标注与反推**：手动标注之外，内置基于卡表相似度的反推建议。
- **段位与巅峰积分**：对局结束后从游戏内存**只读**读取真实段位与 RATE 积分。
- **三语卡名 / 卡组名**：内置约 1.4 万张卡的中 / 英 / 日卡名表。
- **卡图管理**：卡组名管理页可给任意卡组设图 —— 搜卡名挑卡绘、或从站内榜单取图；
  自组卡组（榜单里没有的）也能配图、也能搜到。
- **参照库一键刷新**：看板「设置 → 数据工具 → 参照库刷新」，不用敲命令行。
- **模式筛选可多选**：战绩页与对局分析页都能像 Excel 那样打勾选模式
  （排名决斗 / 巅峰决斗 / DC 杯 / 活动决斗），两页各自独立；勾一下就即时刷新。
- **手坑识别**：自动识别本局前两回合双方用过的 12 张手坑（含异画版本）——
  战绩页最右两列显示卡图（一格最多 5 张，超出 `+N`），
  「对局分析 → 手坑汇总」按我方卡组看**先手 / 后手**两张开局的手坑与胜率。

## 安装与运行

### 下载（[Releases](../../releases/latest)）

| 附件 | 体积 | 需要什么 |
|---|---|---|
| `masterduel-stats-Setup-1.1.3.exe` | ~27 MB | 一键安装。**不要装到 `Program Files`** —— 那个目录对普通用户只读，补丁包覆盖不了程序代码（要管理员权限），数据也会被改存到 `%LOCALAPPDATA%\MasterDuelStats`；请装到普通目录（如 `C:\MasterDuelStats`），数据就跟着程序放在 `<安装目录>\data` |
| `masterduel-stats-v1.1.3-win64-full.zip` | ~39 MB | **什么都不用装** —— 自带 Python 与全部依赖，解压后双击 `MDStats.exe` |
| `masterduel-stats-v1.1.3-patch-win64.zip` | **~0.7 MB** | **老用户升级用**（便携版）—— 只含程序代码，解压覆盖到原目录即可；**不会动你的对局数据** |
| `masterduel-stats-v1.1.3-win64-lite.zip` | ~6 MB | 需先装 Python 3.13；首次运行 `MDStats.exe` 会自动安装依赖 |
| Source code (zip / tar.gz) | 自动 | 源码包，GitHub 对每个 tag 自动附带 |

**从旧版升级（便携版）**：下 `patch.zip`（不到 1MB），
**先完全退出程序与采集器**（托盘图标右键 → 退出），
再把包里 `master-duel-stats` 的内容解压覆盖到原目录。对局数据在 `data/` 里，
补丁包不会碰。安装版直接重下新的 `Setup` 覆盖安装即可。

**关于游戏对局数据的位置**：安装版默认**跟着程序走**（`<安装目录>\data`），
整个文件夹拷到别的电脑就能接着用。

> **不要装到 `Program Files`。** 那个目录对普通用户只读：补丁包在那里覆盖不了
> 程序代码（要管理员权限），而且数据会被改存到 `%LOCALAPPDATA%\MasterDuelStats`，
> 不再跟程序在一起。请选一个普通可写目录（例如 `C:\MasterDuelStats`）。

两种情况都可以在 **看板 → 设置 → 界面 → 游戏对局数据**里改成任意目录
（改完重启界面生效）。

**最省事的做法**：装好 [Python 3.13](https://www.python.org/downloads/)（勾选
*Add to PATH*，或确保 `py` 启动器可用），解压下载包，然后**双击 `MDStats.exe`**。
它会自己找 Python、首次运行自动装依赖（**看得见进度**）、拉起常驻采集器与悬浮窗；
万一出错会**弹窗告诉你原因**并写 `data/launcher.log`，而不是黑框一闪而过。

**想分别手动运行**（在解压后的目录里）：

```
python tools\duel_collector.py     # 常驻采集器
python tools\duel_ui.py            # 悬浮窗 + 看板
```

喜欢脚本的话，`start.bat` 做的是同样的事。

**怎么停止**：点悬浮窗的 ×（X）—— 那会退出整个工具。看板可以从悬浮窗打开，
也可以从托盘图标右键进入。若装了多个 Python，把正确 `python.exe` 的完整路径
写进 `MDStats.exe` 同目录的 `python_path.txt`，它会优先用那个。

### 首次运行

* 数据库**首次启动自动建表**（`data/masterduel.db`），所有数据都在 `data/`；
* **反推卡组 / 参照库**需联网抓一次参照数据（约 2~3 分钟，建议每月刷新）：
  ```
  python tools\fetch_mdm_decks.py --all
  ```
  （等价入口：看板「设置 → 数据工具 → 参照库刷新」，点一下就行）
* **禁限表 / 卡组名称 / 卡组图**：看板设置页有一键工具，按月刷新即可；
* （可选）用 Untapped 公开 API 补录历史对局：把你的账号标识写进
  `data/untapped_ids.json`（格式见 `tools/fetch_untapped_api.py` 顶部说明）。

## 数据与隐私

* 战绩数据来源 = **游戏日志解析 + 只读内存采集**，两条腿互补（见 DESIGN.md）；
* 内存采集**只读**：不写入、不注入、不修改任何游戏文件 ——
  `core/memread/redline.py` 定义禁区清单，`tests/test_memread_guard.py`
  用 25 项单测强制执行；
* 除少数显式点击的联网操作（官网查卡、公开榜单抓取）外，工具不联网；
  战绩库、对局记录、个人状态全部留在本机 `data/`。
